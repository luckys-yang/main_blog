使用 printf 需要注意

  • 只有在检测到 ‘\n’ 时才会从缓存区把数据发出去，因此在数据结尾一定要有 ‘\n’, 否则数据是肯定传不出去的，这次滞留的数据有可能会在下次发送带 ‘\n’ 的数据时随它一块过去，当然也有可能被覆盖，如果真有什么特殊需求不能用 ‘\n’ 的话在发完数据之后就要运行一次 fflush(stdout) 强制刷新一次输出流，这样数据也是能发出去的
  • 编码问题。VSCode 默认使用的编码是 UTF-8 因此如果你的输出有中文的话请找一个支持 UTF-8 的串口助手查看，否则肯定会乱码，不推荐直接改编码为GB2312！！！

串口

空闲中断

空闲中断是接受数据后出现一个byte的高电平(空闲)状态，就会触发空闲中断

为了减少误进入串口空闲中断，串口 RX 的IO管脚一定设置成 Pull-up

串口空闲中断只是接收的数据时触发，发送时不触发

DMA发送

串口发送不配置为DMA，串口配置DMA后， 会有连续两次发送会出现数据丢失的情况，因此不使用

然后注意就是如果用DMA发送的话出现数据乱码大概率就是因为 transmit_data是在封装函数内声明，执行完发送函数就会释放数组，这个时候DMA还没有发送完成，但是发送数据的地址却变了导致发送数据乱

解决方法是：确保DMA发送期间，发送数据地址保持不变。即将transmit_data数据声明为全局变量或者添加Static 修饰

然后就是出现发送数据第一次正常 后面就没有数据 这种一般是MX里串口没勾选 循环模式 导致

串口DMA接收+空闲中断

TC（发送完成）：当该位被置1的时候，表示USART_DR内的数据已经被发送完成了。如果设置了这个位的中断，则会产生中断。该位也有两种清零方式：读USART_SR，写USART_DR；直接向该位写0

RXNE（读数据寄存器非空）：当该位被置1的时候，就是提示已经有数据被接收到了，并且可以读出来了（即RDR移位寄存器中的数据被转移到USART_DR寄存器中）=1时表示收到新数据，读DR自动清零

TXE（发送寄存器空）：=1时才能写入新发送数据

IDLE（检测到总线空闲（连续高电平））

DMA空闲中断+DMA半满和完成中断

半满中断是当DMA传输的一半数据已经传输完成时触发的中断。这个中断可以用来通知CPU，表示已经传输了一部分数据，可以进行相关的处理操作

满中断是当整个DMA传输完成时触发的中断。这个中断用来通知CPU，表示整个数据传输已经完成，可以进行后续的处理

ADC

12位ADC

这个是采样时间

ADC 的转换时间跟 ADC 的输入时钟和采样时间有关

公式为：Tconv = 采样时间 + 12.5 个周期(固定值) 当 ADCLK = 14MHZ （最高），采样时间设置为 1.5 周期（最快），那么总的转换时间（最短）Tconv = 1.5 周期 + 12.5 周期 = 14 周期 = 1us

一个 ADC 时钟周期的时间为 1 / 14MHz = 0.0714286 us

14 个周期的时间就是 14 * 0.0714286 = 1 us

一般我们设置 PCLK2=72M，经过 ADC 预分频器能分频到最大的时钟只能是 12M，采样周期设置为 1.5 个周期，算出最短的转换时间为1.17us，这个才是最常用的

如果设置成最大 239.5 个周期的话采样一次需要20us：

一个 ADC 时钟周期的时间为 1 / 12MHz = 0.08333 us

239.5 + 12.5 = 252

252 * 0.08333 = 20.99916us

一般在设计原理图的时候会把 ADC 的输入电压范围设定在：0~3.3v，因为 ADC 是 12 位的，那么 12 位满量程对应的就是 3.3V，12

位满量程对应的数字值是：2^12。数值 0 对应的就是 0V。如果转换后的数值为 X ，X 对应的模拟电压为 Y，那么会有这么一个等式成立：

2^12 / 3.3 = X / Y => Y = (3.3 * X ) / 2^12

首先看手册支持哪种模式的SPI

这里有写了MODE 0 3两种 如果没写的话可以通过时序图分析CLK空闲时的电平状态

现在先用 CLK空闲时是低电平 这种状态继续往下分析

分析DI和DO是在CLK的上升沿还是下降沿采集数据，注意DI代表从机(W25Q32)的MOSI引脚，DO代表从机(W25Q32)MISO引脚

一般数据是通过DI和DO两个引脚传输的，所以数据有效区(图中绿色框部分)就是，这一时刻，这两个引脚的 只能是稳定高电平或者低电平，相当于数据有效区的电平就是最终要传输的数据位，低电平代表0，高电平代表1，传输8个位，代表1个字节的数据

通过DI和DO在数据有效区时CLK是上升沿还是下降沿，来判断：

从图可以看出，DI和DO在数据有效区时，CLK是上升沿，下降沿的时候，DI和DO处于电平可任意变化的无效数据区

首先上升沿采集数据，通过排除法，这样只有 模式0和模式3 符合条件

然后就是CLK空闲时间要为低电平，这样就只有模式0符合了

分析整体时序

  • 先看DI(也就是w25Q32收到的数据)
  1. 单片机先发送读指令(0x03) 过来，0x03被拆分成8个Bit在DI线上传输，每个CLK上升沿传输1个Bit

  1. 发完读指令以后，单片机继续发24位的内存地址，相当于要读W25Q32c哪个内存地址的数据。这个数据是由单片机程序定的，所以不是固定的，可以看到数据位都是可以高电平，也可以是低电平
  2. 这个时候通信双方的角色就变了，单片机变成了数据接收方，W25Q32变成了数据发送方。因为数据从W25Q32的DO发出了

程序注意

Master 设备的片选操作必须由程序所实现。例如: 由程序把 SS/CS 管脚的时钟信号拉低电平, 完成 SPI 设备数据通信的前期工作; 当程序想让 SPI 设备结束数据通信时, 再把 SS/CS 管脚上的时钟信号拉高电平

CS引脚用IO口控制 默认高电平
