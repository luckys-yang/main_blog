C++语法

构造函数几种写法：

派生类包含基类的所有成员，而且还包括自已特有的成员，派生类和派生类对象访问基类中的成员就像访问自已的成员一样，可以直接使用，不需加任何操作符，但派生类仍然无法访问基类中的私有成员

在Ｃ++中派生类可以同时从多个基类继承

匿名函数(lambda 表达式)

virtual 表示这是一个虚函数，支持多态(运行时根据对象类型调用对应的函数)

std::vector 关键字，C++ 标准库提供的 动态数组容器，可以在运行时自动管理内存（申请、释放、扩容）

override 关键字 明确地表示一个函数是对基类中一个虚函数的重载

在设计一个类的时候，如果我们一个构造函数都没有写，那么 C++ 会帮我们写一个构造函数

如果我们写的类是一个没有那么复杂的类，我们可以不需要写析构函数。如果一个类只要有这些情况：打开文件、动态分配内存、连接数据库。简单的说：就是只要构造函数里面有了 new 这个关键词，我们就需要自己手动编写析构函数

它与构造函数唯一的区别就是，前面都加了一个 ~ 符号

析构函数都是没有参数的，也就是说：析构函数永远只能写一个

vector 是 C++ 标准库（STL）里的 动态数组容器

vector 的大小可以在运行时动态增长或缩减，不需要在编译时确定

可以往 vector 里添加元素（push_back()）、删除元素（erase()）、访问元素（[] 或 .at()）
